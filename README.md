# 배명고 AI연구반 · AI 운세 영수증

> **타 AI/개발자 인수인계:** [HANDOFF.md](./HANDOFF.md) (상세 기술·상태), [PROMPT_FOR_NEXT_AI.md](./PROMPT_FOR_NEXT_AI.md) (복사해 전달할 지시문)


**기능:** 영수증사진 업로드 → 연애운/친구 궁합/오늘의 행운 선택 → 실제 Claude Haiku 5.5 운세 생성 → 화면 공유.
**행운숫자 이벤트:** 같은 요청에서 Claude가 사진의 창의성을 100점 만점(구도·아이디어·표현·재미 각 25점)으로 채점합니다. 이 점수가 **행운숫자**이고, 기기당 처음 1회만 순위에 기록됩니다. 결과 카드에는 전체 상위 10개 점수가 표시되고, `/admin`에서 전체 순위와 확인 코드를 볼 수 있습니다.
**완전히 삭제:** 애니메이션/웹툰 생성, OpenAI 이미지 API, 일회용 영수증 인증.
**인증 범위:** PRO+ 고정 QR을 통해 사이트에 들어옵니다. QR 주소를 아는 사람은 누구나 들어올 수 있으며, 영수증 원본 여부는 기술적으로 검증하지 않습니다.

## 1. 준비
- Node.js 22 이상
- Anthropic API 키 (Claude **유료 앱 구독**과 API 사용 권한/크레딧은 별개일 수 있습니다)
- GitHub 계정, Railway 프로젝트

### 로컬 실행
1. `.env.example`을 `.env`로 복사합니다.
2. `.env`의 `ANTHROPIC_API_KEY`에 **본인의 실제 API 키**를 입력합니다. 키를 ChatGPT나 GitHub에 공유하지 마세요.
3. `npm start` 를 실행합니다. (`npm install` 불필요: 의존성 0개)
4. 브라우저로 `http://localhost:3000`을 엽니다.
5. `http://localhost:3000/api/health`에서 `ok: true`, `apiConfigured: true` 확인.

## 2. Railway 배포
1. **GitHub**에서 새로운 저장소 생성 후 프로젝트 파일 업로드. `.env`는 업로드하지 않습니다.
2. **Railway** > New Project > Deploy from GitHub Repo를 선택해 저장소 연결.
3. Variables에 다음을 등록합니다.
   - `ANTHROPIC_API_KEY` : 실제 Anthropic API 키
   - `ANTHROPIC_MODEL` : `claude-haiku-5-5`
   - `DAILY_API_LIMIT` : 예 `200` (프로세스 메모리 기반 한도)
   - `IP_LIMIT_PER_15MIN` : 예 `200` (학교 공용 Wi-Fi 사용 시 IP가 공유될 수 있으니 현장 테스트 필요)
   - `PORT` : Railway가 자동 제공하는 값을 그대로 사용
   - `DATA_DIR` : (생략 가능) 행운숫자 순위 저장 폴더. 아래 "행운숫자 순위 저장(필수)"에서 Volume을 연결하면 Railway가 주는 `RAILWAY_VOLUME_MOUNT_PATH`를 서버가 자동으로 사용합니다.
4. 배포가 정상 완료되면 Settings > Networking > Public Networking > **Generate Domain**.
5. 실제 `https://...up.railway.app` 주소의 홈페이지와 `/api/health` 확인.
6. 생성된 URL을 PRO+ **영수증사진기+ 앱의 QR 코드 URL 연결** 설정에 등록하세요. 동일한 URL QR을 영수증에 반복 인쇄합니다.
7. 필요하다면 `python scripts/make_qr.py https://실제사이트주소`로 인쇄용 `site-qr.png`를 생성합니다. 이 스크립트에는 `pip install 'qrcode[pil]'`이 필요합니다.

### 행운숫자 순위 저장(필수)
순위는 서버의 `DATA_DIR` 폴더에 `entries.jsonl` 파일로 저장됩니다. Railway는 재배포할 때 일반 디스크를 지우므로 **Volume을 연결하지 않으면 순위가 사라집니다.**
1. Railway 프로젝트에서 서비스에 **Volume**을 추가하고 마운트 경로를 `/data`로 지정합니다.
2. 별도 변수 없이 다시 배포하면 서버가 `RAILWAY_VOLUME_MOUNT_PATH`(= `/data`)를 순위 저장 폴더로 씁니다. (직접 정하려면 `DATA_DIR`을 등록하세요. `DATA_DIR`이 우선합니다.)
3. `https://실제주소/admin`에 비밀번호 없이 접속해 순위가 표시되는지 확인합니다. **확인 코드와 전체 순위도 사이트 주소를 아는 누구에게나 공개됩니다.** 저장소 경고(⚠)가 있으면 순위가 영구 저장되지 않을 수 있습니다.
4. 이벤트 중에는 서버를 재시작·재배포하지 말고, 이벤트 종료 직후 `/admin`의 **CSV 저장**으로 백업해 두세요.

운영 규칙: 순위 기준은 행운숫자(점수)이고, 동점이면 아이디어 → 표현 → 구도 → 재미 점수 순, 그래도 같으면 먼저 제출한 순서입니다. 수상자는 화면의 **확인 코드**와 **실물 영수증**을 함께 보여 주게 하세요. 기기 정보(브라우저 저장소)를 지우거나 시크릿 창을 쓰면 한 기기에서 여러 번 참가할 수 있으므로 완전한 부정 방지는 아닙니다.

### 중요: QR 관련
공개 배포 전에는 실제 외부 접속 주소가 없으므로 **최종 QR 이미지를 만들 수 없습니다**. 예시 주소를 등록하면 연결되지 않습니다. 영수증 QR은 PRO+ 자체 기능으로 생성하는 것이 가장 간단합니다.

## 3. 개인정보 및 운영 주의
- 참가자 얼굴 사진은 AI 운세 생성 시 Anthropic Claude API로 전송됩니다. **사진 처리 동의**를 화면에서 받습니다.
- 이 앱은 이미지 파일을 디스크/DB에 저장하지 않습니다. 요청을 위해 서버 메모리와 AI 제공자의 시스템에서는 처리됩니다. 제공자의 보관/처리 정책은 별도로 확인하세요.
- 행운숫자 순위를 위해 서버에는 **창의성 점수, 확인 코드, 운세 종류, 제출 시각, 해시된 기기 번호**만 저장합니다. 이름·연락처·사진은 저장하지 않으며, 동의 문구에도 이 내용이 안내됩니다. 이벤트가 끝나면 `DATA_DIR`의 `entries.jsonl`을 삭제하세요.
- 점수는 외모가 아니라 포즈·소품·구도·연출 아이디어만 평가하도록 프롬프트에 제한했습니다. 순위표(`/admin`)에는 사진이 없지만 비밀번호 없이 공개되므로 확인 코드와 순위 정보도 누구나 볼 수 있습니다. 상품 이벤트는 학교/담당교사 승인을 받으세요.
- 타인 사진은 동의 없이 업로드하지 않도록 안내하세요. 미성년자가 참여하는 축제이므로 학교/담당교사 승인 및 동의 절차를 우선 확인하세요.
- AI가 외모로 실제 연애 상태, 성격, 미래를 판단하는 것은 아니며, 사진 분위기를 소재로 활용한 **오락용 운세**입니다.
- 현재 사이트에는 **엄격한 영수증사진 전용 인증이 없습니다**. 주소를 아는 사람이라면 접근 가능합니다.

## 4. 비용·보안
- 실제 AI 생성에는 Anthropic API 비용이 듭니다. 비용은 이미지 토큰·출력 토큰·모델 단가에 따라 달라집니다.
- `ANTHROPIC_API_KEY`는 서버 환경변수에만 보관하고 브라우저에 노출하지 않습니다.
- 서버는 파일을 메모리에서만 받고 JSON 입력 크기, JPEG 헤더, 요청 빈도를 제한합니다.
- **중요:** `DAILY_API_LIMIT`는 단일 인스턴스 메모리 기반이어서 서버가 재시작되면 초기화됩니다. 확실한 예산 상한이 필요하면 Anthropic Console의 사용량/지출 알림 및 추가 영속적 예산 제한 기능을 확인하세요.
- 사진을 브라우저에서 최대 변 1000px JPEG로 압축해 EXIF를 제거한 뒤 전송합니다. 브라우저의 처리 지원 여부는 현장 테스트가 필요합니다.
- Railway 인스턴스 여러 개를 띄우면 인메모리 요청 제한은 인스턴스마다 적용됩니다. 학교 행사라면 단일 인스턴스로 먼저 운영하세요.

## 5. QA 체크리스트
- [ ] 모바일에서 카메라 촬영 및 앨범 선택
- [ ] 사진을 업로드하기 전에는 운세 생성 버튼 비활성화
- [ ] 동의하지 않으면 버튼 비활성화
- [ ] 실제 Claude 응답 도착 후 세 가지 운세 각각 표시
- [ ] 2명 이상 촬영된 영수증사진 테스트
- [ ] 오류/과금 한도 초과 시 안내 문구 표시
- [ ] 공유 및 복사 동작 확인
- [ ] PRO+ 영수증 하단의 고정 QR이 실제 사이트로 이동
- [ ] 10~20명 동시 테스트, 학교 Wi-Fi 속도 점검
- [ ] 실제 Claude 응답에 `창의성: 구도=.., 아이디어=.., 표현=.., 재미=..` 줄이 매번 포함되고 행운숫자가 표시되는지 (점수가 안 나오면 "행운숫자를 매기지 못했어요"가 표시되며 참가 기회는 유지됨)
- [ ] 같은 사진을 여러 번 넣었을 때 점수가 너무 흔들리거나 특정 구간에 몰리지 않는지 (필요하면 `server.mjs`의 채점 기준 문장 조정)
- [ ] 같은 기기에서 다시 뽑기를 했을 때 점수·확인 코드가 유지되는지
- [ ] `/admin` 비밀번호 없이 열리는지, 순위·동점 정렬·CSV 저장과 Volume 경고(⚠) 확인
- [ ] 서버를 재시작해도 순위가 남아 있는지 (Volume 연결 확인)

## 7. 원터치 압축 파일 (Windows, 코딩을 모르는 사람에게 전달용)
`dist\AI운세영수증-원터치.zip`을 건네면 됩니다. 받는 사람은 압축을 풀고 `시작하기`를 더블클릭하면 끝입니다. Node.js 설치가 필요 없습니다(압축 안에 포함).
- **API 키는 압축에 들어 있지 않습니다.** 처음 실행할 때 키를 붙여넣게 하고, 키가 유효한지 자동으로 확인한 뒤 `app\.env`에 저장합니다. 키는 따로 전달하세요(채팅·메일 본문보다는 직접 전달 권장).
- 순위 기록은 압축을 푼 폴더의 `순위기록\`에 저장됩니다. 새 행사 전에는 이 폴더 안의 파일을 지우세요.
- 같은 와이파이의 휴대폰에서만 접속됩니다(주소가 와이파이마다 달라지므로 **인쇄 영수증의 고정 QR에는 쓸 수 없습니다. 그 용도는 Railway 배포**). 방화벽 허용이 필요하고, 학교·카페 와이파이는 기기 간 통신을 막는 경우가 많습니다. 주소가 http라서 공유 버튼은 "복사" 창으로 대체됩니다.
- 한도 설정(`DAILY_API_LIMIT` 등)을 바꾸려면 압축을 만들기 전에 `scripts\package\start.ps1`의 기본값(200)을 고치거나, 풀린 폴더의 `app\.env`를 수정하세요.
- 다시 만들기(코드를 고친 뒤): `powershell -ExecutionPolicy Bypass -File scripts\make_package.ps1` — Node 22 LTS를 nodejs.org에서 받아 체크섬을 확인한 뒤 `dist\`에 압축 파일을 만듭니다. 이미 받아 둔 Node zip이 있으면 `-NodeZip 경로`로 지정합니다. `.env`나 키 비슷한 문자열이 들어가면 빌드가 중단됩니다.
