AI 운세 영수증 실행하는 법

송충이 이거 보고 따라 해. 코딩 몰라도 됨.
윈도우 10/11 컴퓨터에서만 돌아감. 설치할 건 없고 인터넷만 되면 됨.


[처음 한 번만 하면 되는 거]

1. 받은 zip 파일 우클릭 -> [모두 풀기] -> [압축 풀기]
   zip 안에서 바로 실행하면 안 됨. 꼭 풀어서 써.
   바탕화면 같은 찾기 쉬운 데 풀어놔.

2. 풀린 폴더에서 「시작하기」 더블클릭

3. 검은 창 뜨면서 API 키 넣으라고 함.
   받아둔 키(sk-ant- 로 시작하는 긴 글자) 복사하고,
   검은 창에서 마우스 오른쪽 클릭 한 번 하면 붙여넣어짐. 그리고 엔터.
   이 키는 요금 나가는 비번 같은 거라서 아무한테도 보내지 말고 사진 찍어서 올리는 것도 하지 마.

4. 하다 보면 이런 창 뜰 수 있는데 다 정상임.
   - "Windows의 PC 보호" (파란 창)
       -> [추가 정보] -> [실행]
   - "Windows 보안 경고" (방화벽)
       -> [액세스 허용] (개인 네트워크 체크된 상태로)
       이거 허용해야 폰에서 들어와짐.

5. 좀 있다가 인터넷 창이 저절로 열리면 성공.


[행사 당일에 켜는 법]

1. 「시작하기」 더블클릭. 이제 설정 같은 거 없이 바로 켜짐.

2. 검은 창에 "휴대폰에서 보기"라고 적힌 주소가 있음.
   그걸 폰 인터넷 창에 치면 들어와짐.
   컴퓨터랑 폰이 같은 와이파이여야 됨.

3. 검은 창은 닫지 마. 닫으면 서버 꺼짐. (작게 내려놓는 건 괜찮음)

4. 행사 중엔 컴퓨터가 안 잠들게 해놨음.
   그래도 노트북이면 충전기는 꽂아놔.


[순위 보는 법 (상품 줄 때)]

- 검은 창에 "순위 보기" 주소가 있음. 거기 들어가서 비번 치면 됨.
- 비번은 「관리자 정보.txt」 파일에 있음. 처음 실행하고 나면 생김. 남한테 보여주지 마.
- 1등부터 쭉 나옴. 수상자는 폰 화면에 뜬 "확인 코드"랑 실물 영수증 같이 보여달라고 해.
- [CSV 저장] 누르면 엑셀용 파일로 저장됨.
- 순위 기록은 「순위기록」 폴더에 저장됨. 지우지 마.


[끝낼 때]

1. 순위 화면에서 [CSV 저장] 해서 기록 빼놔.
2. 검은 창 닫으면 꺼짐.
3. 다음 행사 하기 전에는 「순위기록」 폴더 안 파일 지워야 지난 기록이 안 남음.


[안 될 때]

- 폰에서 주소가 안 열려
    . 컴퓨터랑 같은 와이파이인지 확인해봐.
    . 학교나 카페 와이파이는 기기끼리 연결을 막아놓은 데가 많음.
      그럴 땐 컴퓨터를 폰 핫스팟에 연결하거나 공유기를 따로 써.
    . 방화벽 창에서 [취소] 눌렀으면 「시작하기」 껐다가 다시 켜서 이번엔 [액세스 허용] 눌러.

- "이미 켜져 있어요" 라고 뜸
    정상임. 이미 켜져 있어서 인터넷 창만 열어주는 거야.

- "키를 사용할 수 없대요" 라고 뜸
    키를 처음부터 끝까지 다시 복사해봐.
    그래도 안 되면 키 준 사람한테 물어봐.

- 운세가 안 나오고 오류가 뜸
    좀 있다 다시 눌러봐.
    계속 그러면 키 준 사람한테 크레딧(잔액) 남았는지 물어봐.

- 그래도 안 되면 검은 창 사진 찍어서 보내.


[알아둘 거]

- 이 방식은 이 컴퓨터가 켜져 있는 동안만 됨.
- 영수증 QR로 아무 데서나 들어오게 하려면 인터넷에 올리는 방식(Railway)으로 해야 함.
  컴퓨터 주소는 와이파이 바뀌면 달라져서 QR에 넣을 수가 없음.
- 폰에서 [결과 공유하기] 누르면 이 방식에선 "복사" 창이 대신 뜸.
  보안 연결이 아니라서 그런 거라 정상임.
